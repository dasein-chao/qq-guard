# 宿主手机选型与落地清单

## 结论先行

你问"要足够旧的手机吗"——**方向对，但关键不是旧，是能解锁 root**。

- **别买 iPhone**：iOS 跑不了 QQ 协议端、本地签名、后台常驻。花钱也做不到，这条路直接排除。
- **别指望 iQOO Neo 10**：官方明确 BL 不可解锁，root 封死。
- **要买的是**：一台**能解锁 BL / 能 root 的旧安卓机（arm64）**。前人已在这类机器上跑通"本地签名 + 协议端"，数据不出手机，最安全最稳。

## 为什么"能 root"这么重要

本地签名服务要加载 QQ 的签名库（`wrapper.node`），需要在手机上跑一个完整的 Linux 环境（Debian chroot）。**chroot 需要 root**。免 root 的 Termux 也能试，但保活弱、签名环境没被验证过，不适合当 7×24 宿主。

前人（2026-11-05）在 arm64 安卓机 + Debian chroot + root 上，完整跑通了本地签名 + 协议端，签名函数偏移都已逆向出来。这是唯一被验证过、又满足"数据不出本机"的路线。

## 买什么样的二手安卓机（2026 行情）

**核心要求**：
1. 能解锁 BL / 能 root（小米、红米、一加的旧旗舰最容易）
2. arm64 芯片（下面推荐的都是）
3. 内存 3G+、存储 32G+（够用）
4. 电池健康还行（或直接插电用，电池不重要）
5. 便宜（当挂机专用，不用好屏幕好相机）

**推荐机型**（都能 root，二手价 200-400 元）：

| 机型 | 芯片 | 二手价 | 备注 |
|---|---|---|---|
| 红米 K20 Pro | 骁龙 855 | 180-250 元 | 工作室淘汰机多，很多**已解锁 BL、预装框架**，拿到就能用 |
| 小米 10 / 10S | 骁龙 865/870 | 300-480 元 | 性能强、教程多 |
| 红米 K40 | 骁龙 870 | 300 元 | 功耗稳、不易发热，适合长期挂 |
| 一加 8 | 骁龙 865 | 约 200 元 | 系统干净、解锁 root 友好 |

**购买技巧**：
- 在闲鱼搜"**已解锁 BL**"或"**工作室淘汰机**"，很多卖家已经解锁好、甚至预装了 Magisk/LSP 框架，省去你自己折腾。
- 买前问卖家三句话：① BL 解锁了吗？② 能不能 root？③ 系统是什么版本？
- 不用管屏幕/相机成色（挂机看不见），重点确认能开机、能连 WiFi/插卡、电池不鼓包。

## 落地步骤（买到后照着做，我来带你）

1. **解锁 BL + root**（如果卖家已弄好，跳过）
2. **装 Termux + proot-distro Debian**（免刷机，在安卓里跑 Linux）
3. **提取 QQ 签名库**：下载 QQ Linux arm64 版，取出 `wrapper.node`
4. **搭本地签名服务**：用前人验证的 `ntqq-sign-server`，arm64 偏移 `0x38bf4fc`
5. **部署协议端**：arm64 版 Lagrange，配置指向本地签名服务
6. **扫码登录**：手机 QQ 扫二维码，勾选"下次无需确认"
7. **连上我们的系统**：把 QQ Guard 的 WebSocket 客户端指向协议端
8. **验证**：跑 `verify_live.py`，确认真实消息流进来、P0 提醒响在手机上

> 系统代码侧已全部就绪（58 项测试全过）。真正要做的就是把这台手机环境搭起来。
