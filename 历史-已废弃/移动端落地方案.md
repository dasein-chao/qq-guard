# 落地移动端方案 — 已找到可行路径

## 先纠正我自己

我上一轮建议"电脑装 Linux 搭签名服务"是**错的**，直接违反你早就定好的两条：落地旧手机、电脑不做宿主。已纠正并写进真相文档铁律区。

## 你的直觉是对的：就该落地移动端

**为什么移动端更合适**：你随身带两台手机、旧手机插流量卡常在线、随时有电（充电宝）、固定跟着你走——这正是 QQ 风控最喜欢的"真人行为"。电脑反而要一直插电、怕电池老化、还不能随身带。

**关于电脑常开**（回答你的问题）：
- 24 小时开机不会让电脑"坏"，但笔记本长期满电插电 + 发热会**加速电池老化**。
- 真要长开得设"充电阈值 80%" + 保证散热，麻烦。
- 结论：能开但没必要，**移动端才是正解**。

## 关键突破：移动端本地签名，前人已经跑通了

找到一篇 **2026-11-05（三周前）的真实部署记录**：有人在一台 arm64 安卓手机上，完整跑通了"协议端 + 本地签名服务 + agent"，**签名在本机算，数据不出手机，无远程依赖**。

这同时满足你的三个要求：
1. ✅ 落地旧手机（arm64 安卓）
2. ✅ 签名不出本机（安全，不碰公共 IP）
3. ✅ 不靠电脑常开

### 前人已经解决的难点（我不用重复踩坑）

| 难点 | 前人的解法 |
|---|---|
| arm64 手机能不能跑 QQ 协议端 | 能。官方 QQ Linux 有 arm64 版 |
| 签名核心 wrapper.node 从哪来 | 从官方 arm64 的 QQ 安装包里提取（123MB） |
| arm64 的签名函数偏移没人知道 | 已逆向出来：`0x38bf4fc`（版本 3.2.35-54395） |
| 怎么在手机上跑 Linux | Debian chroot（需 root）或 Termux（无需 root 但弱一些） |
| 内存/存储够不够 | 2.7G 内存够用；约 1.16GB 存储 |

## 唯一的前置条件（需要你确认）

这套方案里最稳的版本**需要旧手机 root**，因为要跑 Debian chroot。所以问你一件事：

**你的旧手机能不能 root？**（一般 Android 16 的机器 root 比较麻烦，但旧机通常可以）

- **能 root** → 走完整方案（Debian chroot + 本地签名），最稳、最接近真人。
- **不能 root** → 退一步用 Termux（免 root），能跑但保活弱一些，需要额外处理后台被杀的问题。
